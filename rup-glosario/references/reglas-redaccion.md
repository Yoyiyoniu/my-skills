# Reglas de redacción: Glosario

Cómo se escribe cada sentencia. Los ID de fuente (F1, F2...) y su nivel de evidencia están en `../../_rup-comun/reglas-comunes.md`.

| ID | Se escribe así | Ejemplo de forma | Fuente |
|---|---|---|---|
| G1 | Definición por categoría más cercana + rasgos que la distinguen. | `Recibo: comprobante que <rasgo que lo distingue>.` | F16 |
| G2 | Decir qué es y qué hace o qué implica en el dominio. | | F15 |
| G3 | Usar otros términos del glosario y vocabulario común mínimo. | | F15 |
| G4 | Según el tipo: actor (quién es y qué hace), objeto (qué es y qué acciones recibe), verbo (quién interviene y qué resulta), estado (qué representa y cómo se llega). | | Resumen secundario de Leite, nivel B |
| G5 | Un solo glosario para el sistema, consistente con el resto de documentos. | | F5 |
| G6 | Descripción corta: un párrafo como máximo. | | F3 |

"Circularidad" significa dos cosas opuestas según la fuente. En el LEL es buena: cada término se define con términos del léxico (F15). En ISO 704 es un defecto: A se define con B y B con A (F16). Se aplican ambas: se reutilizan términos del glosario sin definir uno mediante el otro.
